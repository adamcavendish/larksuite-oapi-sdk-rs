# Security Policy

## Supported versions

Security fixes are made against the latest published crate version. Please
upgrade before reporting a potential issue when possible.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting flow for this repository and include a minimal,
redacted reproduction, affected crate version, enabled features, and impact.

Do not include app secrets, access tokens, tenant data, or real request payloads
in a report.
