# Code of Conduct

We want this project to be a welcoming, professional place to collaborate.

## Expected behavior

- Be respectful and constructive in issues, pull requests, and reviews.
- Discuss technical decisions in good faith and assume others are doing the
  same.
- Keep feedback about ideas and code rather than personal characteristics.
- Respect privacy: never share credentials, tenant data, or private customer
  information.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate disclosure of
private information, and disruption of project discussions are not acceptable.

## Enforcement

The repository maintainer may remove, edit, or reject contributions and
comments that violate this code of conduct. To report a concern privately,
contact the repository owner through their GitHub profile instead of opening a
public issue.
